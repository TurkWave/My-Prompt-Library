# Latest Regulations and Actions

> **Purpose:** This file is used to regularly and chronologically track all changes made to the project.

> **General Structure and Rules:** This section will always remain at the very top, and all new changes will be written according to this template in the **Change Logs** section, with the newest entries always at the top.

> **Note:** If some parts of the template are filled in, write only those parts; do not write the sections that remain empty.

> **Language:** This file is always written in English, regardless of the language used in the conversation.

> **Writing:** Entries are written in plain, natural prose. No em dash and no en dash, one idea per sentence, and a blank line between sections. When an entry names a file, a module or a decision, name it first and then say what changed about it. See `Writing Style Standard.md` in `General Prompt Rules files/` for the full rule.
